# Meu Financeiro — edição somente celular

Interface otimizada exclusivamente para celulares, com navegação inferior, cartões de movimentações e formulários em coluna. Publicação: envie todos os arquivos para a raiz de um repositório GitHub e ative Settings > Pages > Deploy from a branch > main / (root). Abra o endereço HTTPS no Chrome Android e instale pelo menu.

**Segurança:** registros ficam no armazenamento local do navegador, sem criptografia. Não há autenticação nem conexão automática com Nubank, Santander ou APData. Não use senhas ou dados bancários sensíveis. Faça backups CSV e proteja os arquivos exportados. Não há garantia de ausência de falhas.
